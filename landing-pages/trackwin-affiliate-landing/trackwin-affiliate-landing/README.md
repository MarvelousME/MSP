# TrackWin Affiliates Landing Page

Static HTML/CSS/JS landing page for a premium horse racing affiliate platform.

## Files

- `index.html`
- `assets/css/styles.css`
- `assets/js/main.js`
- `assets/img/hero-horse-racing-finish.png`

## Features

- Uses the uploaded hero image directly
- Dark luxury horse racing + fintech dashboard theme
- GSAP 3 + ScrollTrigger CDN
- Animated headings
- Scroll-triggered reveals
- Parallax hero image
- 3D photo-finish card movement
- Animated counters
- Hover tilt cards
- Modern glassmorphism dashboard
- Responsive mobile-first layout

## Usage

Open `index.html` locally or upload the full folder to your hosting environment.
