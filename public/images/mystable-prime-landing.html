Gate 01 — The Engine

RaceVolt, Under The Hood

Four systems work in lockstep on every race: a feature-rich model, a tracked experiment trail, calibrated probabilities, and a reinforcement-learned staking policy.

MODEL

XGBoost Core

Thirty engineered features per runner — form, pace, going, jockey and trainer strike rates — feed a gradient-boosted ensemble tuned for every race class.

TRACKING

MLflow Versioning

Every model run, parameter set and metric is logged and reproducible — so each prediction can be traced back to the exact model that made it.

CALIBRATION

Isotonic Calibration

Raw model scores are mapped to true win probabilities, so a "30% chance" really does win three times in ten.

STAKING

PPO + Kelly Fraction

A reinforcement-learning agent chooses a Kelly-fraction action for every bet — sizing stakes to your edge, not your emotions.
